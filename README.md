# DPIS Legacy — UIS7862S 비공식 CPU 최적화 수정판

> **비공식 수정판입니다. DPIS 원 개발자의 공식 릴리스가 아닙니다.**

## 먼저 말씀드립니다

**저는 개발자가 아니며, 프로그래밍 지식이 아예 없습니다.**

차량용 Android 올인원에서 네이버지도의 글자가 지나치게 작아서, [DPIS](https://github.com/Kwensiu/DPIS)로 앱별 화면 크기를 조정하다가 성능 문제를 겪었습니다.

원본 DPIS Legacy에서는 DPI 조절은 되지만 네이버지도 메뉴가 심하게 버벅였습니다. 이를 개선해 보고 싶어서 ChatGPT에 문제 상황과 실제 기기의 테스트 결과를 설명하며 코드 수정과 APK 빌드를 요청했습니다.

쉽게 말해 **제가 직접 코드를 작성한 것이 아니라, ChatGPT로 딸깍해서 만든 개인적인 수정판입니다.** 이 설명문도 ChatGPT가 작성한 내용을 제가 일부 수정해서 사용하고 있습니다.

저는 실제 기기에서 설치하고 동작 상태를 확인하는 역할을 했습니다. 전문 개발자가 제작하거나 광범위한 기기에서 검증한 소프트웨어는 아니라는 점을 감안해 주세요.

## 프로젝트 목적

UIS7862S 기반 Android 10 차량용 올인원에서 DPIS Legacy의 앱별 화면 크기 조정 기능을 사용하면서 발생한 CPU 부하와 버벅임을 줄이는 것이 목적입니다.

- 앱별 화면 배율·최소 너비·글자 크기 조정 기능 유지
- 화면 정보 조회 과정의 반복 처리 감소
- 이전 계산 결과 재사용 및 캐시 갱신 조건 정리
- Android 10 Legacy 환경의 호환성 보완

UIS7862S를 목표로 수정했지만, 해당 기기에서만 실행되도록 제한하지는 않았습니다.

다만 이는 개인 보유 기기에서 확인한 결과입니다. 모든 배포 버전·기기·앱에서 같은 효과가 나온다는 의미는 아닙니다. 어떤 변경이 성능 개선에 가장 크게 기여했는지도 별도의 프로파일링으로 확정하지 않았습니다.

- 원 개발자의 공식 버전이 아닌 개인 비공식 수정판입니다.

- 삭제·교체 설치가 필요하면 먼저 기존 DPIS 설정을 기록하거나 백업하세요. 앱을 삭제하면 설정이 지워질 수 있습니다.

- 문제가 생기면 후킹 프레임워크에서 모듈을 비활성화한 뒤 재부팅해 확인하세요.

- 저는 개발자가 아니므로 전문적인 분석이나 지속적인 기술 지원을 제공하기 어렵습니다.

## 소스코드 및 빌드 자료

**설치한 APK와 같은 릴리스에 첨부된 공개 소스 ZIP을 사용하세요.**

공개 소스 ZIP에는 다음 자료를 포함합니다.

- 해당 APK에 대응하는 전체 수정 소스
- 수정 내역과 관련 패치
- 원본 라이선스·저작권 및 기여자 고지
- 필요한 타사 라이선스·고지와 관련 소스 자료
- 빌드 환경과 APK 재빌드 방법
- 해당 배포본의 빌드·테스트 검증 자료

**GitHub가 자동 생성하는 `Source code (zip)`과 `Source code (tar.gz)`는 해당 태그의 저장소 스냅샷입니다. APK를 다시 빌드하려면 각 릴리스에 직접 첨부한 공개 소스 ZIP을 사용하세요.**

이전 배포본의 소스가 저장소에 별도 ZIP으로 보관돼 있는 경우, 해당 자료도 이전 APK에 대응하는 소스로 유지합니다.

### 서명 키 안내

공개 소스에는 APK 서명 개인키를 포함하지 않습니다. 직접 빌드할 때는 자신의 서명 키를 만들어 사용할 수 있습니다.

자신의 키로 서명한 APK는 기존 배포 APK와 인증서가 달라 덮어쓰기 설치가 되지 않을 수 있습니다. 이는 소스로 APK를 만들 수 없다는 뜻은 아닙니다.

자세한 빌드·서명 절차는 해당 공개 소스 ZIP의 안내 문서를 참고하세요.

### 검증 결과의 의미

빌드·자동 테스트 통과와 실제 기기에서의 정상 동작은 별개입니다. 검증하지 않은 항목은 해당 릴리스에서 구분해 안내합니다.

또한 빌드 도구·생성 메타데이터·서명 등에 따라 재빌드 APK의 전체 파일 해시가 달라질 수 있습니다. 재빌드 확인 여부와 비교 범위는 각 배포본의 검증 자료를 참고하세요.
