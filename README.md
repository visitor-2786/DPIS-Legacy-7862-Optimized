# DPIS Legacy — UIS7862S 비공식 CPU 최적화 테스트판

> **비공식 수정판 / Unofficial community build.** DPIS 원 개발자의 공식 릴리스가 아닙니다.

저는 개발자가 아닙니다. 차량용 Android 올인원에서 최신 네이버지도의 글자가 지나치게 작아서, [DPIS](https://github.com/Kwensiu/DPIS) 로 앱별 화면 크기를 조정하다가 성능 문제를 겪었습니다. 원본 DPIS Legacy에서는 DPI 조절은 되지만 네이버지도 메뉴가 심하게 버벅였습니다. ChatGPT의 도움으로 코드를 수정하고 테스트용 APK를 빌드했습니다. 해당 글도 ChatGPT가 작성한것에 약간의 수정만 더했습니다.

**제 UIS7862S Android 10 RAM 4GB 기기 / 갤럭시 M20 에서 네이버지도, 티맵에 적용했을 때**, DPI 변경 기능은 유지되면서 체감 버벅임이 거의 사라졌습니다. 
**이것은 개인적인 실기기 체감 결과이며 다른 기기나 앱의 정상 동작을 보증하지 않습니다.**

## 변경 사항 간단 요약

- Legacy의 화면 정보 조회(`getConfiguration`, `getDisplayMetrics`) 중 반복 처리를 줄이고 이전 계산 결과를 재사용하도록 최적화
- 화면 설정이 실제로 변경될 때 캐시를 무효화하도록 조건 정리
- Android 10에서 없는 일부 API에 대한 호환성 처리
- 원본 대비 자세한 변경 사항과 테스트 기록은 각 배포 버전의 소스 자료 및 릴리스 설명을 참조해 주세요.

> **주의:** 어떤 변경이 실제 성능 개선에 가장 크게 기여했는지는 별도로 프로파일링하여 확정하지 않았습니다.

## 다운로드 및 설치 시 주의

- 설치 APK는 GitHub **Releases** 첨부파일을 사용하세요. 저장소 자체에는 수정 소스코드를 공개합니다.
- **배포 APK는 원본 DPIS와 서명 인증서가 다릅니다.** 따라서 원본 버전 위에 바로 업데이트 설치되지 않을 수 있으며, 기존 설정을 백업한 뒤 교체 설치하는 것을 권장합니다.
- GitHub에는 여러 시험 빌드 중 실제 기기에서 동작을 확인하고 공개하기로 결정한 수정판만 배포합니다.
- 새로운 수정판을 배포할 경우, 각 릴리스의 설명에 해당 버전의 변경 사항과 테스트 결과를 별도로 기록합니다.
- 기존 DPIS와 수정판을 동시에 활성화하지 마세요.
- 루팅·LSPosed 모듈은 시스템 안정성에 영향을 줄 수 있습니다. 설치와 사용은 각자 판단해 주세요.
- 위에 명시한 테스트 환경 이외의 기기, Android 버전 및 앱에서는 정상 작동을 보장하지 않습니다.
